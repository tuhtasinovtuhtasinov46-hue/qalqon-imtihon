QALQON IMTIHON — Telegram bot версия

Как это работает:
1. Студент проходит регистрацию на сайте: ФИО, телефон, дата.
2. Выбирает вариант и проходит тест.
3. После кнопки «Завершить» сайт показывает результат студенту.
4. Одновременно результат приходит вам в Telegram.

Что приходит в Telegram:
- ФИО
- Телефон
- Дата тестирования
- Вариант теста
- Правильных ответов
- Неправильных ответов
- Процент
- Время прохождения

Настройка Telegram бесплатно:
1. Откройте Telegram и найдите @BotFather.
2. Напишите /newbot.
3. Создайте бота и получите TOKEN.
4. Узнайте свой CHAT_ID через @userinfobot.
5. Откройте файл app.js.
6. Найдите строки:
   const TELEGRAM_BOT_TOKEN = 'PASTE_BOT_TOKEN_HERE';
   const TELEGRAM_CHAT_ID = 'PASTE_CHAT_ID_HERE';
7. Вставьте туда TOKEN и CHAT_ID.
8. Откройте index.html и проверьте тест.

Важно про безопасность:
Если сайт будет просто HTML/CSS/JS без сервера, TOKEN бота будет виден в коде сайта.
Для личного/тестового использования это самый простой бесплатный вариант.
Для серьёзного публичного сайта лучше сделать маленький backend/proxy, чтобы TOKEN был скрыт.

Если Telegram не настроен:
Сайт всё равно работает, показывает результат и даёт скачать CSV.
